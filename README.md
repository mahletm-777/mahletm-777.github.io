# Mahlet Molla — Academic Portfolio & Tech Blog

Plain HTML/CSS/JS. No build step.

## Deploy to GitHub Pages
1. Create a repo (e.g. `your-username.github.io`) and upload all files, keeping `index.html` at the root.
2. Settings → Pages → Source: "Deploy from a branch" → `main` / `(root)` → Save.
3. Visit `https://your-username.github.io/` after ~1 minute.

## What to edit
- `script.js` section 1: email, social links, highlights, research areas, projects, blog posts.
- `index.html`: page title/description, hero headline & tagline, About paragraphs, contact intro, footer.
- `styles.css` `:root`: colors and fonts.
- `assets/`: replace `profile-photo-placeholder.jpg`, project images, and `cv-placeholder.pdf` (keep names or update paths).
